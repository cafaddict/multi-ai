# Lead's judge checklist

Collect the candidate/report references and independent review reports.
Compare the actual source and acceptance results. Resolve each applicable
blocking finding by report/finding ID with supporting evidence; explain rejected
alternatives and any fallback-related loss of confidence.

Write JudgeResult for the decision, selected candidate/commit, objective checks,
review references, blocker dispositions and remaining risks. For REVISE/BLOCK,
include the next required action in rationale. Apply the integration conditions
in [SKILL.md](../SKILL.md); this checklist does not dispatch a Judge worker.
